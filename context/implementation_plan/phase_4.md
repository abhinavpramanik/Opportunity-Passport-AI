# Phase 4: Dashboard

## Objective
Develop the core dashboard where the user sees their generated Opportunity Passport.

## Tasks
- Build Passport overview cards (resembling Apple Wallet).
- Implement Score widgets (Employability, Learning, Finance, Insurance, Global Mobility).
- Show AI insights and summary sections.
- Create the Notifications center (Apple-style alerts for scholarships, jobs, etc.).
- Assemble the overall Dashboard layout with a premium grid system.

## Notes
- Use glassmorphism and soft shadows.
